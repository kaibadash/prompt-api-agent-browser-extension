# Privacy Policy

**Prompt API Agent**

Last updated: September 24, 2026

Prompt API Agent is a Chrome extension. Its single purpose is to chat with Chrome’s built-in Prompt API and, when you ask, read and operate the active http or https tab from the side panel.

## Certification

I certify that the following disclosures are true:

- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

## Data the extension uses

The extension handles data only to carry out that purpose:

- **Messages you type** in the side panel, and the assistant’s replies.
- **The active tab**, when you ask about it or ask the assistant to change it: its URL, title, visible text, and the interactive elements needed to click, type, choose an option, or scroll.
- **Settings you save**: the model language, and any default instructions you enter.

Chat messages stay in memory for the open side panel. They are discarded when you clear the conversation or close the panel. The extension does not write them to disk.

Settings are stored with `chrome.storage.local` on your device. They remain until you change them or remove the extension.

Page contents and messages are passed to Chrome’s built-in Prompt API so it can answer and perform the actions you requested. This extension does not run its own server and does not send that data to the developer.

## What this extension does not do

- It does not sell user data.
- It does not transfer user data to third parties, except as required to perform the single purpose through Chrome’s built-in Prompt API on your device.
- It does not use or transfer user data for advertising, analytics, or any purpose unrelated to the single purpose.
- It does not use or transfer user data to determine creditworthiness or for lending.
- It does not create an account or ask for an API key.
- It does not read tabs other than the active http or https tab you are using with the assistant.

If you open the Prompt API setup page from the link in the side panel, that page loads in a new tab. This extension does not send your chat or page contents with that link.

## Contact

Questions about this policy can be sent through the Chrome Web Store support link for Prompt API Agent.
